Minecraft Access is available for Fabric or Neoforge on Windows, Linux and Mac.

If you're on Windows, see the [Fabric setup guide]({{% relref "/docs/setup/basic" %}}) (recommended) or the [Neoforge setup guide]({{% relref "/docs/setup/advanced" %}}).

If you're on MacOS, see the [MacOS setup guide]({{% relref "/docs/setup/macos" %}})

Note: Currently there is no setup guide for Linux

Minecraft Access is also a part of the [Visually Impaired Access Mods modpack](https://modrinth.com/modpack/vi-access) available on Modrinth. See the [modpack setup guide]({{% relref "/docs/setup/modpack" %}}).
